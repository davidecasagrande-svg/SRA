# New South Wales Slope Risk Assessment

Field app for slope risk assessment to Transport for NSW standards. One app, one standard per project:

| Standard | Scope | Status |
|---|---|---|
| TS 02136 – Guide to Slope Risk Analysis, Version 4 | Roads | Available |
| TS 00196 – Slope Risk Management (2026) | All modes | In development |
| TS 01637 – Geotechnical Risk Assessment and Hazard Management | Rail | In development |

Live app: https://davidecasagrande-svg.github.io/SRA/

## Editing

Edit the files in `src/`, then run `python3 build.py` to rebuild `index.html` (a single self-contained page that works offline). Never edit `index.html` by hand.

Work is saved on each device only (browser storage). Use **Back up all projects** / **Restore backup** to move it between devices or from the original Slope Risk App.
